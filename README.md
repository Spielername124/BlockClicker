# BlockClicker
## About:
This is a Minecraft Plugin made to allowing to configure different drops that can be "dropped" by breaking any defined block, while allowing as many customization options, like having different loot table in different world guard regions, having different drops depending on  the used Item or luck effects and much more.
There are many different rewards that can be granted, like dropping custom Items, spawning different container like chests, barrels or ovens, with fully customizable loot tables, giving the player effects and more.

## Releases:
Currently, it is still in development, but you can still download the current beta version [here](../../releases/latest).

## Documentation

The best way to see the features in action and see how they can be configured is to check out the [commented standard config](src/main/resources/config.yml), and testing what happens if you change some values. Keep in mind that you always can reload the config with "bc reload"

The full documentation for the config can be found [here](Documentation.txt)


## Dependencies
This plugin is dependent on: WorldEdit, WorldGuard, placeholderAPI
